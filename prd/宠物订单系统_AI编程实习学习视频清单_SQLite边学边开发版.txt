宠物管理订单系统 AI 编程实习
学习视频清单（概念与 Vibe Coding 方向）

============================================================
一、总体学习介绍
============================================================

本学习清单面向没有传统编程经验、实习周期为 1 个月的学习者。

学习者已经完成过大模型基础课程，已经了解以下概念：

- 大语言模型
- 上下文
- 提示词
- 智能体
- Agent Loop 等基本概念

因此，本阶段不再重复学习大模型原理和通用提示词知识。

本次实习的主要方式是：

边学习、边开发、边让 Codex 解释。

实习目标不是系统掌握 Java、Spring Boot、Vue 或 SQLite，也不要求独立手写完整项目。
主要目标是借助 Codex 完成一个“宠物管理订单系统”，并在真实项目中逐步理解软件开发概念。

学习重点：

1. 理解前后端分离项目由哪些部分组成。
2. 理解 Vue、Java、Spring Boot、SQLite 分别负责什么。
3. 理解前端、后端、接口和数据库之间如何配合。
4. 理解项目目录、代码文件、启动命令、日志和报错等基本概念。
5. 学会把产品需求拆成适合 Codex 执行的小任务。
6. 学会让 Codex 先阅读项目、分析影响范围、给出计划，再修改代码。
7. 学会根据页面效果、运行结果和错误日志，让 Codex 持续修正。
8. 在每次功能完成后，能说明前端、后端和数据库分别修改了什么。

建议集中观看视频时间：约 3～4 小时。

建议在实习开始的第 1 天完成核心概念视频。
从第 2 天开始直接进入宠物管理订单系统开发，遇到不理解的概念时，再观看对应视频片段或让 Codex 结合当前代码解释。

不要求提前系统学习：

- Java 完整语法
- Spring 和 Spring Boot 原理
- Vue 3 完整语法
- SQLite 深入原理
- 数据结构与算法
- 设计模式
- Git 命令深入使用
- 微服务、Redis、消息队列
- Linux 和服务器运维
- 独立手写复杂代码

============================================================
二、学习顺序
============================================================

推荐按照“少量概念学习 + 立即进入项目”的方式进行：

第 1 步：
快速理解前端、后端、API、HTTP、JSON 和 SQLite 的作用。

第 2 步：
学习 Codex 的项目操作方式，包括读取项目、制定计划、修改代码、运行验证和继续修复。

第 3 步：
进入宠物管理订单系统，从宠物列表、新增宠物等小功能开始开发。

第 4 步：
开发过程中遇到 Java、Spring Boot、Vue 或 SQLite 概念时，
让 Codex 结合当前代码进行解释，不脱离项目系统学习。

第 5 步：
每完成一个功能，都让 Codex 总结修改文件、数据流和验证方式。

============================================================
五、学习过程中需要理解的软件概念
============================================================

1. 项目
   一组共同完成某个软件功能的文件和目录。

2. 前端
   用户能够看到和操作的页面。
   本项目使用 Vue。

3. 后端
   接收前端请求、执行规则、访问数据库的程序。
   本项目使用 Java 和 Spring Boot。

4. 数据库
   长期保存客户、宠物、服务项目和订单等数据。
   本项目使用 SQLite。

5. API
   前端与后端进行通信的接口。

6. HTTP 请求
   前端向后端发送操作要求，例如查询宠物或创建订单。

7. HTTP 响应
   后端处理完成后返回给前端的数据或错误信息。

8. JSON
   前端与后端之间常用的数据格式。

9. CRUD
   Create：新增
   Read：查询
   Update：修改
   Delete：删除

10. 日志
    程序运行过程中输出的信息，可以帮助定位错误。

11. 编译或构建
    将项目转换为可以运行的程序。

12. 启动
    运行前端或后端服务。

13. 端口
    程序在电脑上提供服务的入口编号。

14. 前后端联调
    让 Vue 页面成功调用 Spring Boot 接口，并正确显示数据库中的数据。

============================================================
七、推荐的 Codex 使用流程
============================================================

每个功能都按照下面的流程完成：

1. 向 Codex 说明本次只处理哪个功能。
2. 让 Codex 先阅读当前项目。
3. 让 Codex 找出相关的前端、后端和 SQLite 数据库文件。
4. 让 Codex 先给出实现计划，不要立即修改。
5. 确认任务范围后再让 Codex 开始修改。
6. 修改完成后让 Codex 编译或启动项目。
7. 查看页面和运行结果。
8. 出现错误时，把完整错误信息交给 Codex。
9. 让 Codex 修复后重新验证。
10. 最后让 Codex 用简单语言总结修改内容。

通用提示词：

请先阅读当前项目，不要立即修改代码。

本次任务：
实现宠物管理订单系统中的【填写具体功能】。

请按照以下步骤执行：

1. 用简单语言说明你对需求的理解。
2. 找出相关的前端、后端和 SQLite 数据库代码。
3. 给出实现计划和准备修改的文件。
4. 一次只完成本次功能，不修改无关模块。
5. 遵循当前项目已有的代码结构和页面风格。
6. 修改完成后启动、编译或测试项目。
7. 检查前端和后端是否存在错误。
8. 用面向编程初学者的方式解释每个修改。
9. 告诉我应该怎样手动验证功能。
10. 不确定的业务规则请先说明，不要自行设计复杂逻辑。

- SQLite 数据库表或数据库文件修改了什么。

- 前端修改了什么。
- 前端如何把数据传给后端。
- 数据最后保存在哪个 SQLite 数据库文件和数据表中。
- 如何判断这个功能已经完成。
- 出错时应该向 Codex 提供哪些信息。

============================================================
九、边学边开发的执行方式
============================================================

从第 2 天开始，不再按照传统课程顺序学习，而是直接开发宠物管理订单系统。

建议功能顺序：

1. 查看宠物列表
2. 新增宠物
3. 修改宠物
4. 删除宠物
5. 客户管理
6. 服务项目管理
7. 创建订单
8. 查看订单列表
9. 修改订单状态
10. 查看订单详情

每开发一个功能，只学习当前需要的概念。

示例一：开发宠物列表时

需要理解：

- Vue 页面是什么
- 表格组件是什么
- GET 请求是什么
- Controller 是什么
- 查询数据库是什么意思
- SQLite 数据表是什么

示例二：开发新增宠物时

需要理解：

- 表单是什么
- JSON 是什么
- POST 请求是什么
- 参数校验是什么
- INSERT 是什么
- 保存成功和保存失败如何返回

示例三：开发订单功能时

需要理解：

- 一对多关系
- 订单和订单明细
- 金额字段
- 订单状态
- Service 业务逻辑
- 多步保存为什么需要一起成功或失败

推荐向 Codex 使用以下学习提示词：

请结合当前宠物管理订单系统中的实际代码，
用编程初学者能够理解的语言解释【填写概念】。

请重点说明：

1. 这个概念在当前功能中负责什么。
2. 对应的是哪个文件和哪段代码。
3. 前端、后端和 SQLite 数据库之间如何传递数据。
4. 我需要理解到什么程度。
5. 哪些深入内容目前可以暂时不学。

每完成一个功能后，再让 Codex 回答：

请总结本次功能：

1. 用户在页面上进行了什么操作。
2. Vue 前端发送了什么请求。
3. Spring Boot 后端如何处理。
4. SQLite 中读取或保存了什么数据。
5. 修改了哪些文件。
6. 应该怎样手动验证功能。
7. 如果功能出错，应该先查看什么日志。
