# 宠物管理订单系统 MVP 验收清单

## 基础验收

- 管理员可以使用 `admin / admin123` 登录系统。
- 首页展示客户总数、宠物总数、服务项目数、待确认订单数、今日预约数。
- 客户支持新增、编辑、查询、启用和停用。
- 宠物支持新增、编辑、查询、启用和停用，且必须关联客户。
- 服务项目支持新增、编辑、查询、启用和停用。
- 可以创建预约订单。
- 创建订单时可以选择客户、该客户名下启用宠物和启用服务项目。
- 订单金额由后端根据服务项目价格快照计算。
- 可以查看订单列表和订单详情。
- 可以按照 PRD 规则修改订单状态。
- 订单状态变化会写入状态日志。

## 业务验收

- 停用客户不能创建新订单。
- 停用宠物不能创建新订单。
- 停用服务项目不能创建新订单。
- 预约时间不能早于当前时间。
- 已取消、已拒绝、已完成订单不能继续修改状态。
- 服务项目价格修改后，不影响历史订单金额。

## 页面入口

- 登录页：`http://127.0.0.1:5173/login`
- 首页：`http://127.0.0.1:5173/dashboard`
- 客户管理：`http://127.0.0.1:5173/customers`
- 宠物管理：`http://127.0.0.1:5173/pets`
- 服务项目：`http://127.0.0.1:5173/service-items`
- 订单列表：`http://127.0.0.1:5173/orders`
- 新建订单：`http://127.0.0.1:5173/orders/create`

## 可选健康记录验收

- 宠物管理页面可以打开某只宠物的健康记录。
- 可以查看疫苗记录、驱虫记录和体重记录。
- 可以新增、编辑、删除疫苗记录。
- 可以新增、编辑、删除驱虫记录。
- 可以新增、编辑、删除体重记录。
- 健康记录不包含自动提醒、附件上传或复杂图表。
